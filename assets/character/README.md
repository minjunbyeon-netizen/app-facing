# 캐릭터 보관함 (assets/character/)

> **여기 있는 그림만 앱에 나온다.** 사용자가 직접 지정·허용한 캐릭터 전용 폴더다
> (2026-08-21 사용자 지시). Claude 가 캐릭터를 만들어 넣지 않는다 — 받아서 꽂기만 한다.

## 그림은 3장이면 끝이다

화면마다 전용 그림을 두지 않는다. **성격(잘됨·안됨·중립) 3가지에만 대응**시키고
전 화면이 그 3장을 돌려 쓴다 (2026-08-21 사용자 결정).

**현재 3장 전부 도착·적용됨** (2026-08-21) — 출처 = `img/file/HYPEE_07-표정시트.png`
(3x3 시트에서 사용자가 지정한 칸: happy=최상단 중앙 · sad=최하단 중앙 · neutral=중앙 우측).
교체하려면 같은 파일명으로 덮어쓰면 된다 — 코드 수정 불필요.

**지금은 스낵바 전용이다** (2026-08-21 사용자 지시 "딱 스낵바부분만").
온보딩·홈 레벨 옆 그림은 **다른 그림을 따로 받아서** 나중에 붙인다 —
그때 `MascotMood` 에 자리를 추가하고 그 그림을 물린다.

| 파일명 | 표정 | 나오는 자리 |
|---|---|---|
| `happy.png` | 웃는 | 완료 스낵바 · 업적 달성 알림(스낵바) |
| `sad.png` | 우는 | 실패 스낵바 |
| `neutral.png` | 담담한 | 안내 스낵바 |

한 장만 줘도 된다 — 있는 것만 그 자리에 나오고, 없는 자리는 조용히 접힌다.

## 그림 조건

1. **배경 없는 PNG** (투명). 배경이 박힌 그림은 화면 어디에 놔도 네모가 보인다
   (구 `mascot.png` 폐기 사유).
2. 정사각 권장. 짧은 변 512px 이상, 한 장 300KB 이하.
3. 스낵바에서는 32px 로 작게 들어간다 — 그 크기에서 표정이 읽혀야 한다.
4. 파일명은 위 표 그대로. 이름이 다르면 안 나온다.

## 파일을 받은 뒤 할 일 (Claude 작업, 2단계)

1. `pubspec.yaml` 의 `- assets/character/` 줄을 살린다.
2. `lib/widgets/mascot.dart` 의 `_assets` 맵에서 해당 줄 주석을 푼다.

경로 문자열은 **`mascot.dart` 밖에 절대 적지 않는다** — 화면 코드에 파일명이
들어가는 순간 이원화다 (글로벌 §0-B).
