> **여기 있는 그림만 앱에 나온다.** 사용자가 직접 지정·허용한 캐릭터 전용 폴더다
> (2026-08-21 사용자 지시). Claude 가 캐릭터를 만들어 넣지 않는다 — 받아서 꽂기만 한다.

## 그림의 정본은 이 폴더가 아니다 (2026-09-04 추가)

여기 있는 파일은 **사본**이다. HYPEE 원본·설정집·재생성 스크립트는 전부 디자인 폴더에 있다.
그림을 고치거나 새 포즈가 필요하면 **거기서** 만들어 이리로 떨군다 — 이 폴더 안에서
이미지를 직접 편집하지 않는다 (글로벌 §0-B 이름 일원화).

| 무엇 | 정본 위치 |
|---|---|
| 앱 규격 에셋 (`flutter/` 1x·2.0x·3.0x · `android/` · `web/` · `master/`) | `C:/dev/services/design/_작업/앱에셋/` |
| 꽂는 절차 · 자리별 크기 · 용량 | `C:/dev/services/design/_작업/문서/앱-에셋-가이드.md` (§4-4 가 이 앱 현황) |
| 캐릭터 설정집 (고정 요소 · 생성 프롬프트 · 포즈 전체 목록) | `C:/dev/services/design/_작업/문서/캐릭터-HYPEE.md` |
| 재생성 명령 | 디자인 폴더에서 `python _작업/스크립트/gen_app_assets.py` |

**정본 재고 26종 중 이 앱에 실린 것은 액션 11종뿐이다** (2026-09-04 실사).
아직 안 실린 것 —

- **마감·인사 6종** `bow` `wave` `thanks` `heart` `cross` `sheepish` (2026-09-04 신규,
  감사·배웅·마감 안내용). 액션 11종이 전부 운동 동작이라 "고맙습니다 / 다음에 만나요"를
  표현할 컷이 없어서 만든 한 벌이다.
- **얼굴 9종** `calm` `happy` `smug` `struggle` `tired` `surprised` `determined` `worried` `wink`.
  위의 스낵바 3장(`happy.png`·`sad.png`·`neutral.png`)과는 별개 세트다.

필요해지면 정본 `flutter/` 에서 **쓸 이름만** 골라 같은 3층(1x·`2.0x/`·`3.0x/`) 구조로
복사하고, `pubspec.yaml` 폴더 등록 + `mascot.dart` 매핑을 추가한다. 26종을 통째로 넣으면
Flutter 세트만 2.96MB 라 APK 가 그만큼 는다 — **골라 넣는 게 기본이다.**

## 그림은 3장이면 끝이다

화면마다 전용 그림을 두지 않는다. **성격(잘됨·안됨·중립) 3가지에만 대응**시키고
전 화면이 그 3장을 돌려 쓴다 (2026-08-21 사용자 결정).

**현재 3장 전부 도착·적용됨** (2026-08-21) — 출처 = `img/file/HYPEE_07-표정시트.png`
(3x3 시트에서 사용자가 지정한 칸: happy=최상단 중앙 · sad=최하단 중앙 · neutral=중앙 우측).
교체하려면 같은 파일명으로 덮어쓰면 된다 — 코드 수정 불필요.

**지금은 스낵바 전용이다** (2026-08-21 사용자 지시 "딱 스낵바부분만").
온보딩·홈 레벨 옆 그림은 **다른 그림을 따로 받아서** 나중에 붙인다 —
그때 `MascotMood` 에 자리를 추가하고 그 그림을 물린다.

| 파일명 | 표정 | 나오는 자리 |
|---|---|---|
| `happy.png` | 웃는 | 완료 스낵바 · 업적 달성 알림(스낵바) |
| `sad.png` | 우는 | 실패 스낵바 |
| `neutral.png` | 담담한 | 안내 스낵바 |

한 장만 줘도 된다 — 있는 것만 그 자리에 나오고, 없는 자리는 조용히 접힌다.

## action/ 하위 폴더는 별개다 (스플래시 연출용)

`assets/character/action/` 에는 **전신 액션 11종**(hesitate·stretch·jumprope·
kettlebell·battlerope·wallball·boxjump·rest·scale·thumbsup·cheer)이 들어 있다.
스플래시에서 카드로 쌓이는 등장 연출 전용이라, 위의 "3장이면 끝" 규칙과 성격이
다르다 — 저쪽은 성격 3종을 전 화면이 돌려 쓰고, 이쪽은 한 번에 다 나오는 한 벌이다.

- 순서·파라미터 정본 = `docs/SPLASH-INTRO-HANDOFF.md`
- 경로 매핑 = `lib/widgets/mascot.dart` 의 `HypeeActions` (여기 밖에 경로를 적지 않는다)
- 2.0x·3.0x 배율본이 함께 있다 (Flutter 자동 인식)

## 그림 조건

1. **배경 없는 PNG** (투명). 배경이 박힌 그림은 화면 어디에 놔도 네모가 보인다
   (구 `mascot.png` 폐기 사유).
2. 정사각 권장. 짧은 변 512px 이상, 한 장 300KB 이하.
3. 스낵바에서는 32px 로 작게 들어간다 — 그 크기에서 표정이 읽혀야 한다.
4. 파일명은 위 표 그대로. 이름이 다르면 안 나온다.

## 파일을 받은 뒤 할 일 (Claude 작업, 2단계)

1. `pubspec.yaml` 의 `- assets/character/` 줄을 살린다.
2. `lib/widgets/mascot.dart` 의 `_assets` 맵에서 해당 줄 주석을 푼다.

경로 문자열은 **`mascot.dart` 밖에 절대 적지 않는다** — 화면 코드에 파일명이
들어가는 순간 이원화다 (글로벌 §0-B).
