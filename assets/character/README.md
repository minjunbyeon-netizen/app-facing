# 캐릭터 보관함 (assets/character/)

> **여기 있는 그림만 앱에 나온다.** 사용자가 직접 지정·허용한 캐릭터 전용 폴더다
> (2026-08-21 사용자 지시). Claude 가 캐릭터를 만들어 넣지 않는다 — 받아서 꽂기만 한다.

## 규칙

1. **넣는 사람은 사용자.** Claude 는 사용자가 준 파일만 이 폴더에 배치한다.
   임의 생성·임의 교체·타 프로젝트 캐릭터 전용 금지.
2. **파일명이 곧 배선 키다.** 아래 표의 이름을 그대로 쓴다 — 이름이 다르면 안 나온다.
3. **배경 없는 PNG** (투명). 배경이 박힌 그림은 화면 어디에 놔도 네모가 보인다
   (구 `mascot.png` 폐기 사유).
4. 정사각 권장. 짧은 변 512px 이상, 한 장 300KB 이하.

## 파일명 ↔ 나오는 자리

| 파일명 | 나오는 자리 | 표정 |
|---|---|---|
| `welcome.png` | 온보딩 첫 화면 (내 정보 입력) | 반기는 |
| `celebrate.png` | 업적 달성 알림 | 축하하는 |
| `cheer.png` | 스낵바 (저장·완료 알림) | 격려하는 |
| `level1.png` | 홈 레벨카드 — Lv 1~10 | 시작 단계 |
| `level2.png` | 홈 레벨카드 — Lv 11~20 | |
| `level3.png` | 홈 레벨카드 — Lv 21~30 | |
| `level4.png` | 홈 레벨카드 — Lv 31~40 | |
| `level5.png` | 홈 레벨카드 — Lv 41~50 | 최종 진화 |

한 장만 줘도 된다 — 있는 것만 그 자리에 나오고, 없는 자리는 조용히 접힌다.

## 파일을 받은 뒤 할 일 (Claude 작업, 2단계)

1. `pubspec.yaml` 의 `- assets/character/` 줄을 살린다.
2. `lib/widgets/mascot.dart` 의 `_assets` 맵에서 해당 줄 주석을 푼다.

경로 문자열은 **`mascot.dart` 밖에 절대 적지 않는다** — 화면 코드에 파일명이
들어가는 순간 이원화다 (글로벌 §0-B). 슬롯이 어디에 뚫려 있는지는 그 파일 주석에 있다.
