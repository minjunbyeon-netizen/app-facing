## 앱 이름
FACING — 박스 운영·수업 관리

## 짧은 설명 (80자 이내)
수업 예약·QR 출석·전자계약·페이싱 엔진. CrossFit 박스 운영을 한 앱에.

## 전체 설명

**One app. Every class.**
FACING 은 CrossFit 박스의 하루를 한 곳에 담는 앱입니다.

**회원이라면**
- 수업 예약 — 주간 일정 확인, 정원 마감 시 자동 대기열
- QR 출석 — 입구 디스플레이 스캔 한 번으로 체크인, 출석 캘린더·스트릭 자동 기록
- 전자계약 — 회원권 계약을 폰에서 확인하고 손가락 서명 (전자서명법 효력)
- 오늘의 WOD — 코치가 올린 WOD·스케일 가이드·기록 제출, 박스 리더보드
- 포인트 — 출석·결제로 쌓이는 박스 포인트

**박스 운영자라면**
- 회원·회원권·코치 관리 (PC 관리자 페이지 연동)
- 수업 개설·정원·대기열 자동 처리
- 전자계약 발급 → 회원 폰 서명 → PDF 보관까지 자동
- 실시간 알림 — 회원의 가입·출석·서명이 PC 화면에 즉시 표시

**FACING 만의 페이싱 엔진**
논문 기반 공식으로 WOD 의 Split 과 Burst 시점을 자동 계산합니다.
1RM·벤치마크를 입력하면 6 카테고리 Engine 점수와 Tier (Scaled–Games) 를 측정합니다.

문의: 카카오톡 채널 (앱 내 고객센터, 평일 10–18시)

## 카테고리·태그
- 카테고리: 건강/운동
- 태그: CrossFit, 크로스핏, 박스, WOD, 체육관 관리
