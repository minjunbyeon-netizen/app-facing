## 도출 기능 그룹 (facing 적용 후보)

1. **수업 예약 (Class Booking)** — 주간 셀렉터 → 슬롯 목록(코치·정원·시간) → 선택 → 확정 → 완료 모달 → 취소 신청. 예약 오픈 윈도우(특정 일시부터) 규칙 포함. (`04~10.jpg`)
2. **회원권 + 홀딩 (Membership + Hold)** — 회원권 종류·기간·D-day·사용 한도, 홀딩 가능 일수/횟수, 기간·사유 입력. (`03.jpg`)
3. **WOD/프로그램 상세 (Workout Detail)** — A/B 프로그램, 동작별 무게·Reps·Sets·rest·영상 링크, `운동 시작하기`. (`00.jpg`)
4. **공지 상호작용 (Notice Engagement)** — 공지 상세에 좋아요·댓글. (`02.jpg`)
5. **WOD/출석 캘린더 (History Calendar)** — 일자별 완료/출석 이력 + 날짜 네비게이션. (`01.jpg`, `10.jpg`)
