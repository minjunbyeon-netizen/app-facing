## 2. 시연 시나리오 (총 17분 · 7 단계)

### Step 0 — 오프닝 멘트 (1분)

> "지금 화면은 페르소나 디버그 모드입니다. 실제 사용자는 못 보고요, 시연용으로 가짜 아이디 4명이 백엔드에 시드돼 있어요. 한 명씩 갈아끼면서 코치 시점, 회원 시점, 박스 안 다닌 사용자 시점이 어떻게 다른지 보여드릴게요. 청중분들이 박스를 운영하시니까, 특히 코치 시점에 시간 많이 쓸 거예요."

### Step 1 — S1 박스 회원 (김도윤) — 2.5분

**의도**: "박스 정보가 회원 앱에 자동으로 박힌다" 입증. 코치가 운영자에게 가장 보여주고 싶은 가치.

1. 페르소나 스위처 → **김도윤** → 적용
2. 하단 `Notice` 탭 진입
3. 상단 박스 정보 카드 4 항목 짚어주기
   - 박스명 **FACING SEONGSU** (헤더)
   - 위치 · 전화 (코치가 박스 등록 시 입력한 그대로)
   - 코치 약력 (한 줄로 정리)
   - 수업 시간표 (줄바꿈 살아 있음)
   - 모토 **Earn it.** (italic quote)

**멘트**: "코치가 박스 정보를 한 번만 등록해놓으면 그 박스 회원 모두에게 자동으로 깔립니다. 회원이 '오늘 몇 시 수업이에요?' 물어볼 일 없어져요."

### Step 2 — S2 무소속 사용자 (송예준) + Scaled 토글 — 2.5분

**의도**: "박스 회원이 아니어도 우리 앱이 돌아간다 → 박스 운영 외에 앱 자체로 사용자 확장 가능" 입증. 코치 입장에서는 "잠재 가입 회원 풀이 앱 안에 이미 있다" 로 들림.

1. 페르소나 스위처 → **송예준** → 적용
2. `Notice` 탭 — 박스 카드 없음 확인
   - **멘트**: "박스에 안 묶인 사람은 코치 공지 받을 일 없으니 카드가 사라져요"
3. 홈 → "Start WOD" → 오늘의 WOD 진입
4. **3 버전 토글 시연** (RX / Scaled / Beginner)
   - RX 버전 보여주기 → Scaled 토글 → 동작이 자동으로 쉬워짐
   - **멘트**: "같은 WOD 인데 본인 수준에 맞춰 3가지 버전이 자동으로 나뉘어요. 박스에 처음 와본 사람이 'RX 못 하겠어요' 할 때 코치가 일일이 대체동작 알려줄 필요 없습니다"
5. 마이페이지 → Engine 점수 (RX 66%) 확인

### Step 3 — S3-A 코치가 박스 정보를 수정 (박지훈) — 1.5분

**의도**: "박스 정보를 코치가 직접 바꾼다 → 운영 권한이 코치 손에 있다"

1. 페르소나 스위처 → **박지훈** → 적용 (자동 코치 모드)
2. 코치 대시보드 → 박스 정보 편집
3. `motto` 한 줄을 즉석에서 변경 (예: "오늘 회의 데모 중") → 저장
4. 페르소나 스위처 → 김도윤 → NOTICE 탭 → 방금 바꾼 모토 즉시 노출 확인
5. **다시 박지훈으로 돌아가서 원래 모토로 복구** ("Earn it.") — 잊지 말 것

### Step 4 — S3-B 코치가 오늘의 WOD 게시 + 회원이 결과 제출 + 리더보드 — 4분 (핵심)

**의도**: "코치 게시 → 회원 자동 경쟁 → 코치가 결과 한눈에 본다" 가치 사다리. **이게 박스 사장 청중이 가장 흥분하는 부분**.

#### 4-A. 박지훈이 WOD 게시 (1.5분)
1. 박지훈 페르소나
2. 코치 대시보드 → "오늘의 WOD 게시"
3. **For Time** 선택, post_date = 오늘, content 예시:
   ```
   "Fran"
   21-15-9
   Thruster 95/65 lb
   Pull-up
   ```
4. 게시 → 200 OK

#### 4-B. 김도윤이 결과 제출 + WOD 댓글 (1.5분)
1. 페르소나 스위처 → **김도윤** → 적용
2. WOD 피드에서 방금 올린 Fran 노출 확인
3. 결과 제출: time_sec = 4:32 (272초), scale_level = rx
4. **WOD 댓글 작성**: "Pull-up 후반에 텐션 떨어졌어요. 다음엔 11-9 분할 시도"
5. **멘트**: "회원들이 WOD 마다 댓글로 코칭 포인트 공유합니다. 박스 안 카톡방 따로 안 만들어도 돼요"

#### 4-C. 박지훈이 리더보드에서 확인 (1분)
1. 페르소나 스위처 → **박지훈** → 적용
2. 코치 대시보드 → 오늘의 Fran 리더보드 진입
3. 김도윤 1위 (4:32) + 미리 시드된 다른 회원 기록들 (정하은·강민재 등) 자동으로 옆에 있음
4. 김도윤이 단 댓글도 같이 보임
5. **멘트**: "회원들이 결과 올리면 자동으로 박스 내 랭킹 만들어집니다. 코치가 엑셀 켜서 정리할 필요 없어요. 댓글까지 한 화면에 모입니다"

> 시드된 다른 회원 기록은 `seed_april_history.py` 가 80건 깔아둬서 자동으로 함께 표시돼요. 박지훈 화면이 비어 보이지 않아요.

### Step 5 — S3-C 가입 승인 + 회원 쪽지 (박지훈) — 2분

**의도**: "신규 회원 가입 처리 + 1:1 코칭이 같은 화면에서 끝난다"

#### 5-A. 최서윤 가입 승인 (1분)
1. 박지훈 페르소나 유지
2. 코치 대시보드 → 가입 요청 → **최서윤 (pending)**
3. "승인" 클릭 → 200 OK
4. (선택) 페르소나 → 최서윤 → NOTICE 탭 → 박스 카드 노출 확인. 시간 빠듯하면 생략하고 멘트로만: "이 사람이 다음에 앱 열면 박스 정보가 자동으로 깔려요"

#### 5-B. 박지훈이 김도윤에게 쪽지 (1분)
1. 박지훈 페르소나
2. 코치 대시보드 → 회원 목록 → 김도윤 → 쪽지
3. 내용: "오늘 Fran 4:32 좋았어요. 다음 주 21-15-9 보다 빨리 갑시다"
4. 송신 → 200 OK
5. 페르소나 → 김도윤 → 인박스에서 받은 쪽지 즉시 확인
6. **멘트**: "코치가 회원 한 명 한 명에게 따로 카톡 보낼 필요 없습니다. 결과 본 자리에서 바로 쪽지 갑니다"

### Step 6 — S4 배지·달성 (김도윤) — 2분

**의도**: "회원이 박스 떠나지 않게 만드는 게이미피케이션 장치가 깔려 있다 → 회원 유지율"

1. 페르소나 → **김도윤** → 적용
2. 마이페이지 → Achievements (FIFA 스타일 grid 화면)
3. **시선 끌 포인트**:
   - 좌측 featured 배지 (대형) — 가장 최근 획득
   - 우측 3×3 grid — 체크된 거 / 진행 중 / 잠금
   - 카테고리 chip: ALL · TIER · STREAK · PR · SEASON
   - rarity 4단계 컬러 바 (Common · Rare · Epic · Legendary)
4. 진행 중 배지 1~2개 짚어주기 (예: "Streak 30일 — 현재 12일")
5. **멘트**: "회원이 박스 안 빠지고 계속 오게 만드는 장치예요. PR 갱신 · 연속 출석 · 시즌 배지를 자동 계산해서 회원이 다음 목표를 항상 보게 합니다. 박스 retention 신경 쓰시는 사장님들 핵심 가치예요"

### Step 7 — 마무리 멘트 (1분)

> "정리하면 4명으로 우리 앱이 박스 운영에 어떻게 들어가는지 다 보여드렸어요. (1) 박스 정보가 회원 앱에 자동 동기화, (2) 코치가 WOD 게시하면 회원 결과·댓글·랭킹이 자동으로 모이고, (3) 1:1 쪽지·승인까지 한 화면에서 끝나고, (4) 배지로 회원 retention 까지 챙깁니다. 박스 안 다니는 사람도 자체 WOD 로 끌어들일 수 있어서 잠재 회원 풀이 앱 자체에 있어요. 운영자 분들이 보시기에 어디가 가장 마음에 드시는지 들려주세요."

| 점수가 0% | 최신 master 인지 확인 (커밋 `864538d` 이후 스케일 수정됨) |
| 페르소나 스위처가 안 보임 | release 빌드로 깔림 → `flutter run` (debug) 재설치 |
| 박지훈이 박스 정보 수정한 게 회원 화면에 반영 안 됨 | 김도윤 페르소나 적용 후 NOTICE 탭 진입 시 자동 refresh. 안 되면 탭 다른 데 한 번 갔다 오기 |

## 부록 A. 페르소나 device_id 해시 산식

`hash_device_id(seed) = SHA256("facing_default_salt" + seed)` hex digest 앞부분.
`.env` 에 `SECRET_KEY=...` 가 설정돼 있으면 솔트가 그 값으로 바뀝니다. 시연 직전 SECRET_KEY 가 default 인지 한 번만 확인.

## 부록 B. 들어내고 안 보여줄 것들 (의도적 제외)

회의 가치 대비 시간 손해라서 다음은 데모 안 들어가요.
- B박스(FACING GANGNAM) + 그 박스 페르소나 5명 (이수민·강민재·윤지원·한수아 등) — 같은 시점 중복
- WOD 히스토리 추이 그래프 — 시각적 임팩트 약함
- 회원 사전 건의(`/requests`) — 운영자 가치 있지만 시간 더 들어 다음 회의로
- 코치 피드백(`/feedback`) — 쪽지로 대체
- 페르소나 30명 자동 생성 — 회원 명단 풍성함은 시드된 6명만으로 충분
