# 용어 사전 (표기 SSOT)

> **정본.** 화면 문구·문서·카피가 이 표와 다르면 **이 파일이 이긴다.**
> 적용 범위: `apps/facing-app` · `web/facing-admin` · `services/facing` **3면 전부**.
> 상위 규칙: `docs/ARCHITECTURE_BRIEF.md §2-0` 3면 공통 대전제 1번 — "사장 = 코치, 같은 급".
> 신설: 2026-08-12 (사용자 지시 — "코치랑 사장이란 말 따로 쓰는 그런 거 아예 없애라").

---

## 0. 한 줄 원칙

**박스를 운영하는 사람은 전부 '코치' 하나로 부른다.**
사장·오너·점주·관리자·매니저·짐매니저는 **이 제품에 없는 말**이다. 창업자든 고용된 코치든
표기는 '코치' 하나뿐이며, 권한도 역할로 가르지 않는다 (대전제 1번).

---

## 1. 사람 — **역할은 딱 셋** (2026-08-12 사용자 지시)

> "코치(사장이자 매니저이자 모든 것) · 회원 · 회원신청자(뉴비) 딱 3개밖에 없다."
> 권한 정본 = `docs/ARCHITECTURE_BRIEF.md §2-0-1`. 넷째 역할 신설 금지.

| 역할 | **정본 표기** | 금지 표기 |
|---|---|---|
| 박스를 운영·관리하는 사람 (창업자·고용 코치 구분 없음) | **코치** | 사장, 사장님, 오너, 점주, 대표, 관리자, 운영자, 매니저, 짐매니저, 보스, Boss, Owner, Admin, Manager |
| 박스에 다니는 사람 | **회원** | 유저, 사용자, 이용자, 고객, 당신, 귀하 |
| 가입 신청을 넣고 심사를 기다리는 사람 | **회원신청자** | 뉴비(UI), 신청자, 승인대기자, 예비회원, 가입 대기 |

- **super admin(서비스 운영자)은 아직 없다.** 필요해지면 그때 넷째로 추가한다.
- 아래는 **역할이 아니라 상태**다 — 사람을 부르는 말로 쓰지 않는다.

| 상태 | **정본 표기** | 금지 표기 |
|---|---|---|
| 심사에서 거절됨 | **거절됨** | 거부됨, 반려 |
| 박스를 나감 | **탈퇴** | 이탈, 해지회원, 퇴회 |

> 회원에게 보이는 문장에서 코치를 높여 부르지 않는다 — "코치님께 문의" 가 아니라 **"코치에게 문의"**.
> (경어 표기가 섞이면 같은 사람이 화면마다 다른 급으로 보인다.)

## 2. 장소·사물

| 대상 | **정본 표기** | 금지 표기 |
|---|---|---|
| 크로스핏 체육관 | **박스** | 체육관, 헬스장, 짐, 센터, 지점, 매장 |
| 코치가 올리는 그날의 운동 | **WOD** | 오늘의 운동, 프로그램(단독), 루틴 |
| 시간표에 있는 수업 1회 | **수업** | 클래스(한글 문장 안), 세션, 강습 |
| 회원권 | **회원권** | 멤버십(한글 문장 안), 이용권, 정기권 |
| 사물함 | **락커** | 라커, 로커, 보관함 |

> **도메인 영문 고정어는 그대로 둔다** — `WOD` `AMRAP` `EMOM` `RX` `RX+` `Scaled` `Elite`
> `Games` `1RM` `PR` `UB` `Metcon` `For Time` `Engine` `Split` `Burst` · 단위 `kg/lb` · `XP` ·
> 벤치마크 WOD 이름(Fran 등) · 동작명(Thruster 등). 근거 = `docs/DESIGN-SSOT.md §7` (v1.29 한글 기본).

## 3. 동작

| 대상 | **정본 표기** | 금지 표기 |
|---|---|---|
| 회원이 수업 자리를 잡는 것 | **예약** | 신청, 등록, 부킹 |
| 자리가 차서 줄 서는 것 | **대기** | 웨이팅, 예약대기, 대기열 |
| 그날 박스에 왔다는 기록 | **출석** | 체크인, 참석, 출석체크 |
| 회원이 자기 WOD 결과를 남기는 것 | **저장** | 제출, 등록, 기록하기 |
| 코치가 WOD를 회원에게 여는 것 | **게시** | 발행, 배포, 오픈 |

> 버튼 이름은 **동작 하나만** 쓴다. 부수 효과를 이름에 끌고 들어오지 않는다 —
> `제출하고 출석` (X) → `저장` + 아래 한 줄 "저장하면 오늘 출석도 함께 기록됩니다." (O).
> v2.6 (2026-08-12 사용자 지시 "이게 무슨 흐름이야, 저장하기로 하던가").

### 난도 표기 순서 (고정)

**SCALED → RXD → ELITE.** 낮은 것부터 오른쪽으로. 뒤섞으면 셋 사이의 위아래가 안 읽힌다.
백엔드 enum 값은 `scaled` / `rx` / `elite` (표기만 RXD, 2026-05-30 통일).

### 회원 레벨 = **경력 기준 3단** (2026-08-12 사용자 지시)

| 크로스핏 경력 | 레벨 |
|---|---|
| 1년 미만 | **SCALED** |
| 1년 ~ 3년 | **RXD** |
| 3년 이상 | **ELITE** |

- 레벨은 **경력 하나로만** 정한다. Engine 점수·앱 사용량으로 산정하던 구 방식
  (2026-06-08 결정)은 폐기 (프로필 ENGINE 섹션 제거 = D34 와 같은 줄기).
- 회원 레벨 사다리에 **RX+ 와 Games 는 없다** — 위 셋뿐이다.
  (WOD 결과 1건에 붙는 `scale_level` 도 같은 셋: `scaled`/`rx`/`elite`.)
- 권한 정본·구현 상태 = `docs/ARCHITECTURE_BRIEF.md` **D36**.

## 4. 이 사전이 손대지 않는 곳 (코드·계약)

**사람이 읽는 문자열만 통일한다.** 아래는 식별자·계약이라 그대로 둔다 —
대신 **화면 문구로 새어 나오면 안 된다.**

| 그대로 두는 것 | 예 |
|---|---|
| DB 값 | `gym_managers.role = owner\|boss\|coach\|manager`, `gym_members.status` |
| API 경로 | `/api/v1/admin/*` |
| 코드 심볼·파일명 | `GymState.isOwner`, `BossDashboardScreen`, `FakeBossApi`, `lib/features/boss/**` |

**번역 지점은 한 곳뿐이다 — `lib/core/role_labels.dart` 의 `roleKoLabel()`.**
운영자 role 이면 값이 무엇이든 **'코치'** 하나를 돌려준다. 새 화면은 이 함수만 쓰고,
화면 코드에 '사장'·'오너' 를 직접 타이핑하지 않는다.

> 심볼·DB 값까지 rename 하려면 백엔드·PC 웹을 같은 커밋에서 함께 고쳐야 한다
> (글로벌 §0-B 이름 일원화). 별도 작업으로 승인받고 진행할 것 — 지금은 **표기만** 통일된 상태다.

## 5. 자동 게이트

`test/copy_lint_test.dart` 의 **'운영자 호칭 1종' 테스트**가 `lib/**.dart` 의 비주석 라인에서
§1 금지 표기를 잡는다. 새로 쓰면 `flutter test` 가 깨진다.
문구를 늘릴 땐 이 표와 테스트 패턴을 **같은 커밋에서** 함께 고친다.
