## §7. 약점·갭

1. **가격 비공개**: 월 요금 수치 사이트 미공개. 상담 의존 → 가격 비교 불투명, 구매 결정 속도 저하
2. **AI 기능 Beta 딱지**: AI 코칭·운동 처방 엔진 모두 "Beta" 단계. 실제 신뢰도·정확도 검증 미완
3. **CrossFit 특화 알고리즘 부재**: WOD 텍스트 작성·유튜브 링크 수준. 페이싱·W-prime·CGM 등 퍼포먼스 데이터 기반 분석 없음
4. **1RM·벤치마크 성과 분석 없음**: 회원 기록 로그는 있으나 엘리트 선수 퍼포먼스 티어링(Scaled/RX/RX+/Elite/Games) 부재
5. **Open/Competition 대응 부재**: 크로스핏 Open 성적 연계·대회 전략 분석 기능 없음 (대회 정보 링크 수준에 그침)
6. **수익 모델 투명성 낮음**: 트랜잭션 수수료·추가 기능 비용 미공개
7. **다국어/글로벌화 초기**: 영문 사이트(`/en/`) 존재하나 북미 진출은 계획 단계 (2025-11 발표)
8. **소규모 스타트업 리스크**: 설립 2023-11, Seed 단계. 장기 지속성 불확실성 존재

## §9. facing 차별화 권장 (3건)

### 권장 1. "연산 엔진 = facing, 운영 SaaS = linko.my" 수직 분리 포지셔닝

linko.my 는 박스 운영(결제·예약·알림·다지점) 에 집중. facing 은 경기 성과(퍼포먼스 측정·페이싱·티어) 에 집중. 두 서비스는 **겹치지 않는 다른 레이어**다.

포지셔닝 문장: "linko.my 는 체육관을 운영한다. facing 은 선수를 훈련시킨다."

박스 운영자가 링코로 회원관리 + facing 으로 선수 코칭을 병행하는 **상호 보완적 구도** 가능 — 경쟁이 아닌 파트너 관계로 접근할 수 있음 (링코 파트너 박스 채널을 통한 facing 보급 가능성 검토 가치 있음).

### 권장 2. CrossFit Open·대회 시즌 특화 기능으로 완전 비교 불가 영역 확보

linko.my 는 대회 정보 링크 수준에 그침. facing 이 **Open 성적 → 티어 업데이트 → 다음 시즌 페이싱 조정** 루프를 완성하면 엘리트 선수/코치 입장에서 대체 불가 서비스가 됨. 특히 한국 CrossFit Open 참가자 수 성장세를 감안하면 시즌 중 바이럴 트리거 확보 가능.

### 권장 3. "선수용 분석 앱" 포지션 유지 — 운영 SaaS 기능 추가 유혹 차단

linko.my 가 AI 기능을 강화하더라도 facing 의 핵심(W-prime·Split·Burst 알고리즘)은 운영 SaaS 가 복제하기 어려운 도메인 전문성 영역. facing 이 결제·예약·다지점 기능을 추가하면 오히려 linko.my 에 비해 열위인 영역에서 경쟁하게 됨 — 스코프 크리프 위험. MVP 는 퍼포먼스 분석 딥다이브에 집중하고 운영 기능은 링코 파트너십으로 대체하는 전략이 현실적.
