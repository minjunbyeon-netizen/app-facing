2026-09-07 · 회원 앱 · 정본 = lib/widgets/hkit.dart HkBadge · 값 = lib/core/appkit.gen.dart

왼쪽은 지금 실물을 코드 값 그대로 옮긴 것이고, 오른쪽이 제안입니다. 아직 코드는 한 줄도 고치지 않았습니다 — 보고 정하시라고 만든 그림입니다.

먼저 정정합니다. 점검 보고서 §2 에 "주 행동 '완료 표시' 가 옆의 '메시지 · 자세히' 와 같은 외곽선 배지" 라고 적었는데 사실이 아닙니다. '완료 표시' 는 2026-08-12 부터 selected: true 라 이미 채움입니다. 실제로 외곽선인 주 행동은 '예약' 쪽입니다. 그래서 제안도 그만큼 작아집니다.

1. 수업 줄 — 예약할 수 있는 상태

2. 이미 예약한 줄 — 주 행동이 없는 상태

지금

'예약됨' 은 상태, '취소' 는 보조 행동 — 둘 다 외곽선으로 남습니다. 채움은 그 줄에서 제일 하고 싶은 일 하나에만 씁니다.

3. 펼친 글 — 완료 표시 · 못 누르는 이유

지금

제안
완료 표시 메시지 자세히
수업 시작 전 메시지 자세히

'수업 시작 전' 은 버튼이 아니라 이유입니다. 테두리를 벗기면 눌러도 안 된다는 것이 모양으로 먼저 보입니다 (탭하면 서버 문구 스낵바가 뜨는 동작은 그대로 둡니다). 같은 자리 = '예약 필요' · '회원권 필요' · '마감' · '취소됨'.
