## P0 — 론칭 차단 (5건)

1. **[인증] 소셜 로그인 백엔드 부재** — 앱 `social_auth_service.dart:136` → `POST /api/v1/auth/social`, `staff_link_screen.dart:51` → `POST /api/v1/auth/link-staff` 인데 백엔드에 auth 블루프린트 없음 (실호출 404). 현재 기본 경로는 `StubSocialAuthService` = 무인증 진입. 실 OAuth 켜는 순간 로그인 전면 불가.
2. **[인증] 로그인 rate limit noop** — `api/admin.py:422-437` `_rate_limit_login` 이 pass 만 하는 장식 데코레이터. wrong pw 8연속 실측 차단 없음. `@limiter.limit("5 per 5 minutes")` 실적용 필요.
3. **[계약] 회원 계약 조회·전자서명 전면 403** — `api/contracts.py:329, 382` 가 `m.device_hash != device_id` 로 해시와 raw 헤더를 직접 비교 (`hash_device_id()` 누락). 본인 계약 상세 실호출 403 재현. 2줄 수정으로 복구 가능.
4. **[온보딩] 신규 회원 가입 신청 고아 라우트** — `/signup/self`(SelfSignupScreen)·`/onboarding/create-gym` 이 main.dart 등록만 있고 push 하는 코드 0건 = 앱 내 도달 불가. "수업 관리 앱" 포지셔닝의 핵심 플로우 단절. (+ self_signup 성공 시 `/home` 으로 보내는데 표준 진입점은 `/shell`)
5. **[관리자웹] 계약서 다운로드·QR 검증 404** — `contracts.html:213` `window.open('/api/v1/admin/contracts/<id>/pdf')` 가 비프록시 경로라 8081 에서 404 (실측). `:207` QR 검증 링크 `/api/v1/contracts/<id>/verify` 도 8081 404. `/api/proxy/...` 경로로 교체 필요.
