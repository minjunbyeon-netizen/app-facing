- 운영 기간: 오픈 1주차

**운영 컨텍스트**
성수동 신규 박스, 회원 40~50명. 혼자 운영 중. 처음 사용하는 박스 SaaS라 셋업 순서를 모른다. 코치 1명을 곧 고용할 예정이라 권한 위임 기능도 궁금하다.

**기능 Job**

**편의성 기대**
Setup wizard (박스 설정 → 코치 추가 → 첫 회원 등록) 가 단계별 안내 없이도 30분 안에 완료되어야 한다.

**회원관리 effort target**
50명 이하지만 만료일 추적·문자 발송 수동 제로. 알림 자동화로 주 1시간 → 0분 목표.

**발화 예시 (마찰 시)**

환불 승인 요청 원클릭. 입력 오류 시 즉각 경고 (잘못된 금액·중복 결제).

**회원관리 effort target**
100명 체크인 러시아워(오전 6~7시) 처리 대기 줄 없이 1인당 10초 이하.
