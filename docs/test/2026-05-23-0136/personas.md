## p1. 이재훈 (38세·데스크톱)

> 개발자 출신 창업 사장. CrossFit 박스 오픈 3개월차. GitHub·Notion 능숙. "운영 자동화가 곧 경쟁력"이라 믿음.

- **기능 Job**: 신규 회원 가입 신청 즉시 알림 + 1분 안에 등록·회원권 지정·계약서 발행까지 원스텝 완료
- **감정 Job**: 내가 직접 만든 시스템처럼 모든 흐름을 장악하고 싶다
- **피하고 싶은 실수**: 회원 신청이 들어왔는데 알림 놓쳐서 당일 입장을 못 시킨 경우 — 첫인상 망침
- **짜증 트리거**: 회원 등록 플로우가 3개 탭을 거쳐야 완료되는데, 중간에 저장 안 됨 메시지 없이 폼이 리셋됨
- **인내심 임계**: 회원 1명 신규 등록에 90초 초과하면 UX 실패로 판단하고 Webhook 직접 만들 생각 함
- **발화 예시 #1**: "회원 신청 들어오면 바로 알림 오는 거 맞지? 슬랙 연동 같은 거 없어?"
- **발화 예시 #2**: "이거 API 문서 어딨어? 그냥 내가 붙이는 게 빠르겠다."

- **피하고 싶은 실수**: 회원이 현금으로 냈는데 시스템에 안 잡혀 2개월 뒤 세금 신고 때 발견하는 상황
